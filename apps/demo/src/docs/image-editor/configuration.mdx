# Configuration

Every aspect of the editor is driven by a single `config` object passed to
`<ImageEditor>` or `<ImageEditorModal>`. This page is the top-level reference —
each tool has its own guide with the full option tables.

## Overview

Pass a `config` prop to customize behavior. Every field is optional.

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    tools: ["crop", "adjust", "filter", "text", "shapes"],
    defaultTool: "crop",
    export: {
      formats: ["png", "jpeg", "webp"],
      defaultFormat: "png",
      quality: 0.92,
    },
  }}
  onSave={handleSave}
/>
```

## ImageEditorConfig

| Option | Type | Default | Description |
|---|---|---|---|
| `tools` | `ImageEditorToolId[]` | all | Tools to show, in order. See [Customize the Toolbar](/docs/image-editor/guides/customize-toolbar). |
| `defaultTool` | `ImageEditorToolId \| null` | `null` | Tool activated on load. |
| `theme` | `ThemeConfig` | `{ preset: "dark" }` | Colors, radius, and font. See [Theming](/docs/image-editor/theming). |
| `colors` | `string[]` | built-ins | Swatch palette (hex) shared by every color picker. |
| `crop` | `CropToolConfig` | — | [Crop Tool](/docs/image-editor/guides/configure-crop) options. |
| `adjust` | `AdjustToolConfig` | — | [Adjust Tool](/docs/image-editor/guides/configure-adjustments) options. |
| `filter` | `FilterToolConfig` | — | [Filter Tool](/docs/image-editor/guides/configure-filters) options. |
| `text` | `TextToolConfig` | — | [Text Tool](/docs/image-editor/guides/configure-fonts) options. |
| `shapes` | `ShapesToolConfig` | — | [Shapes Tool](/docs/image-editor/guides/configure-shapes) options. |
| `image` | `ImageToolConfig` | — | [Image upload](/docs/image-editor/guides/image-upload-limits) limits. |
| `ui` | `UIConfig` | — | Chrome and sidebar options (below). |
| `export` | `ExportConfig` | — | Output formats and save behavior. See [Export & Save](/docs/image-editor/guides/export-and-save). |
| `customTools` | `CustomTool[]` | — | Register your own tools. See [Add a Custom Tool](/docs/image-editor/guides/custom-tool). |
| `locale` | `string` | `"en"` | Active locale. See [Localize the UI](/docs/image-editor/guides/localize). |
| `translations` | `Record<string, string>` | — | Override individual translation strings. |
| `translateFn` | `(key: string) => string` | — | Custom lookup, called instead of the built-in dictionary. |

## Available tools

| Tool | ID | Description |
|---|---|---|
| Crop | `"crop"` | Crop, rotate, flip, resize with presets |
| Adjust | `"adjust"` | Brightness, contrast, saturation, etc. |
| Filter | `"filter"` | Instagram-style photo filters |
| Text | `"text"` | Rich styles and editable layered compositions in a searchable gallery |
| Shapes | `"shapes"` | Filled, outlined, gradient, image, and abstract graphics in searchable categories |
| Image | `"image"` | Image overlay annotations |

## Text presets

`config.text` controls typography defaults and the Text gallery. See
[Configure Text](/docs/image-editor/guides/configure-fonts) for authored block,
run-style, and composition examples.

| Option | Type | Default | Description |
|---|---|---|---|
| `fonts` | `string[]` | built-ins | Font families shown in text controls. |
| `defaultFontFamily` | `string` | first font | Family for new text. |
| `defaultFontSize` | `number` | `24` | Reference size at a 1080px canvas. |
| `defaultColor` | `string` | `"#ffffff"` | Fill for new text when the preset omits one. |
| `presetGroups` | `PresetGroup<TextPreset>[]` | built-ins | Replace the complete built-in gallery. |
| `additionalPresetGroups` | `PresetGroup<TextPreset>[]` | — | Append groups; matching group ids merge presets. |
| `presets` | `TextStylePreset[]` | — | Deprecated flat compatibility list. |

## Shape presets

`config.shapes` controls the Shapes gallery and insertion defaults. See
[Configure Shapes](/docs/image-editor/guides/configure-shapes) for gradients,
image fills, strokes, and custom paths.

| Option | Type | Default | Description |
|---|---|---|---|
| `presetGroups` | `PresetGroup<ShapePreset>[]` | built-ins | Replace the complete built-in gallery. |
| `additionalPresetGroups` | `PresetGroup<ShapePreset>[]` | — | Append groups; matching group ids merge presets. |
| `presets` | `string[]` | — | Deprecated shape-kind compatibility list. |
| `defaultColor` | `string` | `"#3b82f6"` | Fallback color for new shapes. |
| `defaultOpacity` | `number` | `1` | Starting opacity from `0` to `1`. |
| `defaultSize` | `number` | `0.5` | Canvas-relative size when a preset omits `sizeFraction`. |

Preset authoring types, including `PresetGroup`, `TextPreset`, `ShapePreset`,
and composition types, are exported from `@editx/image-editor`.

## Export

`config.export` controls the save step. Full walkthrough in
[Export & Save](/docs/image-editor/guides/export-and-save).

| Option | Type | Default | Description |
|---|---|---|---|
| `formats` | `("png" \| "jpeg" \| "webp")[]` | all | Formats offered in the export dialog. |
| `defaultFormat` | `"png" \| "jpeg" \| "webp"` | first | Pre-selected format. |
| `quality` | `number` | `0.92` | Encoder quality (0–1) for lossy formats. |
| `closeAfterSave` | `boolean` | `false` | Call `onClose` after an unchanged full-document export. Partial page exports keep the editor open. |
| `filename` | `string` | derived | Base filename for the built-in download. |

## UI

`config.ui` tunes the editor chrome. See [Customize the Toolbar](/docs/image-editor/guides/customize-toolbar)
and [Customize the Chrome](/docs/image-editor/guides/customize-chrome).

| Option | Type | Default | Description |
|---|---|---|---|
| `toolSidebar.compact` | `boolean` | `false` | Collapse the tool rail to icons only. |
| `toolSidebar.groupSeparators` | `boolean` | `true` | Dividers between tool groups. |
| `title` | `string` | — | Title shown in the topbar. |
| `showTitle` | `boolean` | — | Toggle the topbar title. |
| `showCloseButton` | `boolean` | auto | Show the close (X) button. |
| `showBackButton` | `boolean` | `false` | Use a back arrow instead of X. |
| `unsavedChangesWarning` | `boolean` | `true` | Confirm before closing with unsaved changes. |
| `projectFiles` | `boolean` | `false` | Show separate Open/Save Project controls for editable `.editx` archives. Assets/fonts are referenced, not embedded. |
| `pageNavigation` | `boolean` | `false` | Show all full-size pages with numbered titles, hover/selection outlines, and undoable page-management controls, without a thumbnail strip. |
| `pageLayout` | `"vertical" \| "horizontal"` | `"vertical"` | Canvas arrangement when page navigation is enabled; independent of persisted scene layout. |

### Multi-page navigation

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{ ui: { pageNavigation: true, pageLayout: "vertical" } }}
  onReady={({ engine }) => {
    engine.scene.addPage({ width: 600, height: 800 });
  }}
/>
```

The strip follows scene page order, shows names and active state, and scrolls horizontally
when the editor container is narrow. Clicking a thumbnail activates and fits that page.
All full-size pages remain on one continuous canvas. Set `ui.pageLayout` to `"horizontal"`
for a side-by-side arrangement, or keep the default `"vertical"` stack.
Wheel scrolling pans along the layout axis; Ctrl/Cmd-wheel still zooms.
Clicking a canvas page activates it without moving the camera.
The [multi-page playground](/playground/pages) starts with three editable social posts
and offers both arrangements. Its side list activates and fits the chosen post;
canvas clicks preserve the camera. `PageNavigationLayout` is exported for typed configuration.

Navigation does not create undo history or write authored visibility. Native saves retain
all pages, including those currently outside the view. The setting defaults to `false`;
disabling it restores the previous engine view mode.

During crop or inline text editing, page controls are disabled until editing finishes.
External SDK navigation still works and clears old page-editing UI. Navigation does not
generate thumbnails; `engine.exportPageThumbnail` remains available separately.
Initialization failures are shown explicitly
instead of silently displaying overlapping pages.

Select a page background or title to show a top properties bar with **Resize** and
**Color**, plus a floating **Duplicate page** / **...** action bar near the page's top edge.
The menu offers **Rename page**, **Move page earlier/later**, and **Delete page**.
**Add page** is always available in a bottom-center footer, independent of selection,
and appends a blank page using the scene's default dimensions. Compact, stable header and footer
lanes prevent canvas shifts on selection and keep the button clear of page content.
Fits use 24px padding. Page captions stay screen-sized and move inside their page at very
low zoom when the gap is too small. The floating action bar uses the page's top-right edge
so the caption remains readable.
Selecting artwork hides the page bars, but not Add page. Add page is temporarily disabled
during crop or inline text editing. Double-click a page title to open
**Rename and resize page** directly, without changing artwork double-click behavior.
Background colors are drafted locally until **Apply color**, then committed in one undoable
operation while preserving existing transparency. The properties dialog
saves name and dimensions atomically; resizing does not scale or reposition artwork.
New and duplicated pages are activated, selected, and fitted. Deleting the active page
fits its fallback; attempting to delete the final page shows an error without mutation.
All operations use public engine page APIs and are undoable. These controls are enabled
only with `ui.pageNavigation`, preserving the default single-image UI.

With `ui.pageNavigation`, **Export Image** opens an **Export pages** dialog:
**Current page** exports the active page as an image; **Selected pages** offers a page
checklist independent of artwork selection; **All pages** includes every document page.
Selected and All always produce one ZIP, including a one-page selection.
Files follow document order, retain each page's dimensions, and use safe numbered
names such as `01-Cover.png`. Canvas filtering never limits All pages.

`onBeforeSave` and `onSave` each receive the final blob once. ZIP output uses
`application/zip`; image-only processing must check the MIME type. Async save callbacks
are awaited. Failed exports report an error and keep the dialog open without saving
a partial ZIP. Without `ui.pageNavigation`, legacy scene export is unchanged.
Partial exports retain unsaved changes and do not auto-close the editor; only a
complete, unchanged export can mark the document clean and honor `closeAfterSave`.
Document edits or replacement during rendering abort export for a safe retry.
See [Export & Save](/docs/image-editor/guides/export-and-save) for callback examples.
