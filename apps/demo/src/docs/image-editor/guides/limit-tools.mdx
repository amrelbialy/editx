# Limit the Tools

Show your users only the editing tools they need. Passing `config.tools` renders
the listed tools in order and hides every other built-in tool.

## When to use this

- You want a focused editor (e.g. crop-only for avatars, or adjust-only for photo tweaks).
- You're embedding the editor in a flow where the full toolset would overwhelm users.
- You need the tool order to match your product's information hierarchy.

## Configure the tools

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{ tools: ["crop", "adjust"] }}
/>
```

Valid tool ids: `crop`, `adjust`, `filter`, `text`, `shapes`, `image`. Omit
`config.tools` entirely to show all of them.
