# Customize the Theme

Match the editor to your brand by overriding individual theme colors and the
corner radius through `config.theme`. Color overrides map to CSS variables (e.g.
`primary` → `--primary`) and `borderRadius` maps to `--radius`.

## When to use this

- Your product has a brand accent color the editor should adopt.
- You want the editor's rounding to match the rest of your UI.
- You need a light tweak rather than a full theme — for that, see [Theming](/docs/image-editor/theming).

## Override colors

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    theme: {
      colors: { primary: "#ff3366" },
      borderRadius: "0.75rem",
    },
  }}
/>
```

Any color you omit falls back to the active preset (dark or light), so you only
specify what you want to change.
