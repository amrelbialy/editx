# Configure the Crop Tool

Ship the Crop tool with output sizes that match your product. `config.crop.resizePresets`
adds one-click resize targets — social formats, thumbnails, print dimensions — to
the Crop tool's **Resize** tab.

## When to use this

- Your users export to fixed sizes (e.g. a 1080×1080 avatar or a 1200×630 share card).
- You want to remove guesswork by offering named, on-brand output dimensions.
- You're building a template flow where every export must land on an exact size.

## Configure the presets

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    crop: {
      resizePresets: [
        {
          label: "Social",
          presets: [
            { label: "Square", width: 1080, height: 1080 },
            { label: "Portrait", width: 1080, height: 1350 },
            { label: "Story", width: 1080, height: 1920 },
          ],
        },
      ],
    },
  }}
/>
```

Each `ResizePresetGroup` has a `label` and a list of presets; every preset needs a
`label`, `width`, and `height`. The first three presets in a group show up front,
with a **More** toggle for the rest.
