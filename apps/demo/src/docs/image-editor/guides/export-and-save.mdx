# Export & Save

Control the save step end to end: which output formats users can pick, how the
rendered blob is transformed before it leaves the editor, and whether the editor
closes itself once the save completes.

## When to use this

- Your pipeline only accepts certain formats (e.g. JPEG-only uploads).
- Every export must carry a watermark, or be re-encoded before you store it.
- The editor lives in a modal that should dismiss itself after a successful save.

## Config reference

| Option | Type | Default | Description |
|---|---|---|---|
| `export.formats` | `("png" \| "jpeg" \| "webp")[]` | all | Formats offered in the export dialog. |
| `export.defaultFormat` | `"png" \| "jpeg" \| "webp"` | first | Pre-selected format. Must be one of `formats`. |
| `export.quality` | `number` | `0.92` | Encoder quality (0–1) for lossy formats. |
| `export.closeAfterSave` | `boolean` | `false` | Call `onClose` after an unchanged full-document export; partial page exports stay open. |
| `export.filename` | `string` | derived | Base filename for the built-in download when no `onSave` is provided. |
| `events.onBeforeSave` | `(blob: Blob) => Blob \| Promise<Blob \| undefined> \| undefined` | — | Transform the rendered blob before `onSave`. |

## Choose the output formats

Restrict the choices with `export.formats` and pick the default with
`export.defaultFormat`.

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    export: {
      formats: ["png", "jpeg"],
      defaultFormat: "jpeg",
    },
  }}
/>
```

`defaultFormat` must be one of the listed `formats`. Omit `export` to offer every
supported format. Open the export dialog — only **PNG** and **JPEG** are offered,
with JPEG pre-selected:

<GuideScenario config={{ export: { formats: ["png", "jpeg"], defaultFormat: "jpeg" } }} />

## Export multiple pages

Enable `config.ui.pageNavigation` to add page targets to the existing export dialog.
**Current page** is the default and downloads one image at that page's dimensions.
**Selected pages** opens a page checklist, independent of canvas/artwork selection.
**All pages** exports every document page, including pages filtered out of the canvas view.

Selected and All always return a ZIP, even for one page. Entries follow document order,
keep each page's own dimensions, and have safe, unique numbered names such as
`01-Cover.png` and `02-Poster.png`. The chosen PNG/JPEG/WebP format and quality apply
to every image. Empty selections are disabled.

Without `onSave`, the ZIP downloads with the configured base filename and a `.zip`
extension. With `onSave`, it receives one `application/zip` blob; it is not called once
per page. The Web Component's `save` event similarly carries the final blob.
Async save callbacks are awaited, and rejected saves or page export failures display
an error while keeping the dialog open for retry. No partial ZIP is delivered.

`onBeforeSave` also receives the complete ZIP once, so image-only transforms must
check its type:

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{ ui: { pageNavigation: true } }}
  onSave={(blob) => uploadToServer(blob)}
  events={{
    onBeforeSave: async (blob) => {
      if (blob.type === "application/zip") return blob;
      return stampWatermark(blob);
    },
  }}
/>
```

The default single-image mode still uses legacy scene export.

Partial exports do not mark the whole document saved and do not auto-close the editor,
even when `closeAfterSave` is enabled. Only an unchanged export covering every page
can clear unsaved changes and auto-close. New edits while an async save callback is
pending remain unsaved. Replacing a document resets the export selector to Current page;
changes or replacement during page rendering abort the operation for a safe retry.

## Transform the blob before save

`events.onBeforeSave` receives the rendered `Blob` and returns a replacement —
ideal for stamping a watermark, re-encoding, or handing off a processed copy to
your backend.

```tsx
<ImageEditor
  src="/photo.jpg"
  onSave={(blob) => uploadToServer(blob)}
  events={{
    onBeforeSave: async (blob) => {
      const watermarked = await stampWatermark(blob);
      return watermarked; // return undefined to keep the original
    },
  }}
/>
```

`onBeforeSave` runs after the scene renders and before `onSave` (or the built-in
download). Return a `Blob` to replace the export, or `undefined` to keep the
original. It can be async, so awaiting canvas work or a network call is fine.

Click **Export Image → Save**. The hook below stamps a repeating **© EDITX**
watermark onto the rendered image, so the file you download is the watermarked
version — not the original:

<GuideScenario events={{ onBeforeSave: stampWatermark }} />

## Close after save

In modal or full-screen flows, users expect the editor to get out of the way once
they've saved. `config.export.closeAfterSave` calls your `onClose` handler
automatically after a successful export.

```tsx
<ImageEditor
  src="/photo.jpg"
  onSave={(blob) => uploadToServer(blob)}
  onClose={(reason) => {
    if (reason === "save") closeModal();
  }}
  config={{ export: { closeAfterSave: true } }}
/>
```

`onClose` receives a `reason` — `"save"`, `"close-button"`, `"back-button"`, or
`"escape"` — plus a `hasUnsavedChanges` flag. After a successful export the reason
is `"save"` with no unsaved changes, so you can close without a discard prompt.
In multi-page mode, this requires exporting every page without intervening edits;
partial exports keep the editor open.

This editor has `closeAfterSave` enabled — export to see the save flow complete:
