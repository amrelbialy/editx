# Save & Restore Scenes

Persist editable artwork through the imperative editor handle from `onReady`.
For new integrations, use `handle.engine.document`: it saves versioned native
JSON with document identity and metadata, separately from active-page navigation.

## When to use this

- You want to persist work-in-progress and resume it later.
- You're building host-managed autosave or drafts. Undo history itself is not persisted.
- You need to script the editor from outside (headless, tests).

## Capture the handle

The canonical document API is available through the existing handle:

```ts
const json = handle.engine.document.saveToString();
await handle.engine.document.loadFromString(json);
```

Store this JSON as a database value or `.editx.json` file. Loading native
documents selects the first root page; store navigation separately if needed.
This is not an asset-bundled `.editx` archive. See
[Document API](/docs/engine/document-api) for the schema, resource limitations,
legacy compatibility, and load-error behavior.

For downloadable editable files, use `handle.saveProject()` / `loadProject()` or
enable `ui.projectFiles`. See [Editable Project Files](/docs/image-editor/guides/project-files);
B5 archives include dependency manifests and a preview but do not embed images/fonts.

### Existing scene integrations

The following example and live demo intentionally exercise the compatible legacy
handle methods. They save raw scene JSON, including active-page navigation:

```tsx
import { useRef } from "react";
import { ImageEditor, type EditorHandle } from "@editx/image-editor";

function Editor() {
  const handle = useRef<EditorHandle | null>(null);

  return (
    <>
      <ImageEditor src="/photo.jpg" onReady={(h) => (handle.current = h)} />
      <button onClick={() => localStorage.setItem("scene", handle.current!.saveScene())}>
        Save
      </button>
      <button onClick={() => handle.current!.loadScene(localStorage.getItem("scene")!)}>
        Restore
      </button>
    </>
  );
}
```

`onReady` fires once when the engine is ready and hands you an `EditorHandle`:

- `saveScene()` returns a JSON string of the entire scene.
- `loadScene(json)` restores a scene previously produced by `saveScene()`.
- `engine` is the underlying engine instance for advanced/headless use.

Neither persistence path saves undo history. Successful loading clears history.
Legacy scene loading creates a fresh document identity; canonical document loading
preserves its saved ID and metadata.
