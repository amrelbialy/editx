# Localize the UI

Set the active `locale` and override individual strings with `translations`.
Keys use dot-notation (e.g. `tools.crop`) and fall back to the default English
copy when a key is missing.

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    locale: "es",
    translations: { "tools.crop": "Recortar" },
  }}
/>
```
