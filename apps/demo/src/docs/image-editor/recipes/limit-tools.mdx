# Limit the available tools

Show only a subset of the built-in tools by passing `config.tools`. The sidebar
renders the listed tools in order; every other tool is hidden.

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{ tools: ["crop", "adjust"] }}
/>
```

Valid tool ids: `crop`, `adjust`, `filter`, `text`, `shapes`, `image`.
