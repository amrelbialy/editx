# Customize the theme

Override individual theme colors and the corner radius via `config.theme`. Color
overrides map to CSS variables (e.g. `primary` → `--primary`) and
`borderRadius` → `--radius`.

```tsx
<ImageEditor
  src="/photo.jpg"
  config={{
    theme: {
      colors: { primary: "#ff3366" },
      borderRadius: "0.75rem",
    },
  }}
/>
```
