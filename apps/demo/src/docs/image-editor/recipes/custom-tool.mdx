# Register a custom tool

Add your own tool with `config.customTools`. Each entry provides an `id`, a
`label`, an `icon` component for the sidebar, and a `panel` component shown when
the tool is active.

```tsx
const StickersTool = {
  id: "stickers",
  label: "Stickers",
  icon: StickersIcon,
  panel: StickersPanel,
};

<ImageEditor
  src="/photo.jpg"
  config={{ customTools: [StickersTool] }}
/>
```
