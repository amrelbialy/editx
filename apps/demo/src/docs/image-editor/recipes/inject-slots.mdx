# Inject custom UI via slots

The `slots` prop lets you render your own React nodes into named regions of the
editor chrome — without forking the component. Here we add a **Share** button to
the top bar.

```tsx
<ImageEditor
  src="/photo.jpg"
  slots={{
    topbarRight: <button type="button">Share</button>,
  }}
/>
```

## Try it

Look for the **Share** action in the top-right of the toolbar:
