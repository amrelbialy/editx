# Engine API

The `EditxEngine` class is the main entry point for the engine.

## Properties

| Property | Type | Description |
|---|---|---|
| `block` | `BlockAPI` | Block manipulation API |
| `editor` | `EditorAPI` | Editor state, viewport, and edit mode |
| `event` | `EventAPI` | Block lifecycle event subscriptions |
| `scene` | `SceneAPI` | Scene and page management |

## History

Command-backed document edits are tracked for undo/redo outside silent mode.
Scene creation and loading establish a new baseline and clear history.

```ts
engine.undo();
engine.redo();
engine.canUndo(); // boolean
engine.canRedo(); // boolean
engine.clearHistory();
```

## Batching

Batch multiple mutations into a single undo step:

```ts
engine.beginBatch();
engine.block.setPosition(id, 10, 20);
engine.block.setRotation(id, 45);
engine.endBatch(); // single undo step
```

## Silent Mode

Suppress history tracking temporarily:

```ts
engine.beginSilent();
// ... mutations won't be recorded in history
engine.endSilent();
```

## Active Scene & Page

```ts
engine.setActiveScene(sceneId);
engine.getActiveScene(); // number | null
engine.setActivePage(pageId);
engine.getActivePage(); // number | null
```

## Events

```ts
// Generic event bus
const handleUndo = () => { /* ... */ };
engine.on("history:undo", handleUndo);
engine.off("history:undo", handleUndo);

// Typed subscriptions (return unsubscribe function)
const unsubscribeHistory = engine.onHistoryChanged(() => { /* ... */ });
const unsubscribeZoom = engine.onZoomChanged((zoom) => { /* ... */ });
const unsubscribePan = engine.onPanChanged(({ x, y }) => { /* ... */ });
const unsubscribeMode = engine.onEditModeChanged(({ mode, previousMode }) => { /* ... */ });
const unsubscribeTransform = engine.onBlockTransform(({ block, phase }) => { /* ... */ });
```

## Export

### Export a page by ID

```ts
const blob = await engine.exportPage(pageId, {
  format: "webp", // "png" | "jpeg" | "webp"; default "png"
  quality: 0.92, // finite 0-1; ignored for PNG
  pixelRatio: 2, // finite and positive; default 1
});
```

The page must belong directly to the active scene, but need not be active. Output uses
that page's dimensions, background, owned content, and child order, clipped to its bounds.
Other pages and uncommitted crop/transform previews are excluded. Authored visibility and
opacity are honored independently of view-only page filtering.

Export never changes activation, selection, camera, group context, document state,
history, or redo, and emits no document events. Concurrent exports capture independent
committed content before waiting; later edits affect later exports only.

The built-in Konva adapter waits for target page images, image fills, background images,
processing, and fonts used by text before layout. Browser-observable font loading failures
reject; a missing family may still resolve to a system fallback until a font registry exists.

Catch the public `PageExportError` to inspect `code` and `pageId`. Codes are
`NO_ACTIVE_SCENE`, `PAGE_NOT_FOUND`, `NO_RENDERER`, `UNSUPPORTED_RENDERER`,
`IMAGE_LOAD_FAILED`, `FONT_LOAD_FAILED`, and `RENDER_FAILED`. Identified resource errors
also include `blockId`, `resource` (source or family), and `cause` where available.
CORS-tainted images, empty canvas output, and MIME/encoder mismatches reject rather than
silently returning another format. Invalid options reject with `TypeError` or `RangeError`.

`RendererAdapter.exportPage` is optional for backward compatibility. Implementations must
capture committed state before awaiting resources and avoid live renderer changes.
Adapters without the capability reject page export; no activation-based fallback is used.

### Generate a page thumbnail

```ts
import type { PageThumbnailExportOptions } from "@editx/engine";

const options: PageThumbnailExportOptions = { maxWidth: 320, maxHeight: 180 };
const blob = await engine.exportPageThumbnail(pageId, options);
const url = URL.createObjectURL(blob);
// Consumer cleanup:
URL.revokeObjectURL(url);
```

Defaults are `maxWidth: 256`, `maxHeight: 256`, `format: "png"`, and `quality: 0.92`.
Bounds must be positive integers; JPEG/WebP quality must be finite in `[0, 1]`.
The page fits within both bounds without cropping, padding, stretching, or upscaling.
Request a larger box for higher density instead of supplying a pixel ratio.
Raster dimensions follow `exportPage` canvas rounding, including fractional dimensions
rounding down and zero-pixel results rejecting explicitly.

The helper uses `exportPage` at a uniformly reduced scale, with the same resource
readiness, authored visibility, identified errors, and no live editor/history changes.
It works with existing page-export-capable adapters; no thumbnail renderer method is needed.

Each engine retains at most 64 successful results using least-recently-used eviction.
Identical concurrent requests share one render. Failed requests are evicted and can retry.
Content-derived keys track the page and owned descendants/shape/fill/effect dependencies,
so silent changes, outer batches, undo/redo, and native loads reusing IDs stay correct.
Only changed pages miss the cache, except that shared dependencies affect each owner.
Page navigation and scene page order do not invalidate otherwise unchanged thumbnails.
Returning to equivalent content may reuse an earlier result.

In-flight calls retain invocation-time content; consumers should guard against an older
request replacing a newer UI preview. Engine disposal clears cached references and rejects
late thumbnail completions. Cached values are `Blob`s; consumers manage their object URLs.
Changing bytes behind an unchanged image URL or externally changing font availability
is not detectable from document content. Use versioned image sources and updated font
descriptors until the asset/font registry milestones add resource invalidation.

### Existing scene and block exports

Existing scene export is unchanged:

```ts
const blob = await engine.exportScene({
  format: "png",   // "png" | "jpeg" | "webp"
  quality: 0.92,   // 0—1, for jpeg/webp
  pixelRatio: 2,   // DPR multiplier
});
```

Export an individual graphic, text, image, or group into a fixed output frame:

```ts
const blob = await engine.exportBlock(blockId, {
  width: 1200,
  height: 630,
  padding: 24,
  pixelRatio: 2,
});
```

Width and height must be positive integers. Padding must be nonnegative and leave
a positive inner frame; pixel ratio must be positive. Missing blocks, unsupported
block types, and engines without a renderer reject the promise.

## Color utilities

```ts
import { colorToHex, hexToColor } from "@editx/engine";

hexToColor("#2563eb");   // alpha = 1
hexToColor("#2563eb80"); // parses 8-bit alpha
colorToHex({ r: 0.15, g: 0.39, b: 0.92, a: 0.5 }); // "rgba(38,99,235,0.5)"
```

## Lifecycle

```ts
engine.dispose(); // clean up renderer and image cache
```
